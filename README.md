# Волшебное путешествие

Интерактивная презентация на 12 слайдов о новогодних и сезонных традициях народов России. Это единственный вариант проекта. Основа оформления — крупные иллюстрации, короткие подписи и озвучка; управляет презентацией ведущий, аудитории не нужны устройства или ответы.

## Запуск

Откройте `quest.html` в браузере или запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем откройте `http://localhost:8000/`. Стрелки `←` и `→` переключают слайды, `F` включает полноэкранный режим. На слайде с регионами карточки меняют иллюстрацию; кнопка «На весь экран» открывает её целиком.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` автоматически публикует корень репозитория при обновлении `main`. Для первичной настройки в GitHub откройте **Settings → Pages** и выберите **Build and deployment → Source: GitHub Actions**. После сохранения workflow можно запустить вручную из вкладки **Actions** или опубликовать новым коммитом в `main`.
