# Волшебное путешествие

Интерактивная презентация на 13 слайдов о новогодних традициях народов России — календарном, лунном и городском Новом годе. Это единственный вариант проекта. Основа оформления — крупные иллюстрации, короткие подписи и озвучка; управляет презентацией ведущий, аудитории не нужны устройства или ответы.

## Запуск

Для корректной загрузки интерактивного глобуса как ES-модуля запустите локальный HTTP-сервер из корня проекта:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем откройте `http://localhost:8000/`. Стрелки `←` и `→` переключают слайды, `Home` и `End` ведут к началу и концу, `F` включает полноэкранный режим. На втором слайде интерактивный глобус вращается автоматически; его можно перетаскивать мышью или пальцем и приближать колёсиком/кнопками. Нажатие на подпись города открывает его зимнее превью. На региональных слайдах кнопка «На карте» открывает тот же глобус с примерной отметкой места; из окна можно перейти в Google Earth. На отдельном слайде зимних городов превью открываются нажатием.

## Атрибуция визуальных и программных компонентов

- Текстура земного шара — **Blue Marble: Next Generation with Topography and Bathymetry (July 2004)**, NASA Earth Observatory / NASA Goddard Space Flight Center. Источник: [NASA Science](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/). Атрибуция приведена для ясности; текстура NASA получена с официальной страницы и используется как картографическая подложка.
- Рендерер глобуса — **Three.js 0.187.0**, лицензия MIT; текст лицензии находится в `vendor/THREE-LICENSE.txt`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` автоматически публикует корень репозитория при обновлении `main`. Для первичной настройки в GitHub откройте **Settings → Pages** и выберите **Build and deployment → Source: GitHub Actions**. После сохранения workflow можно запустить вручную из вкладки **Actions** или опубликовать новым коммитом в `main`.
