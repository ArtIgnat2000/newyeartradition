# Волшебное путешествие

Интерактивная презентация на 12 слайдов о новогодних и сезонных традициях народов России. Это единственный вариант проекта. Сквозные герои — путешественница Мира, лисёнок Искра и оленёнок Тёпа; они сопровождают показ от карты до финала. Основа оформления — крупные иллюстрации, короткие подписи и озвучка; управляет презентацией ведущий, аудитории не нужны устройства или ответы.

## Запуск

Откройте `quest.html` в браузере или запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем откройте `http://localhost:8000/`. Стрелки `←` и `→` переключают слайды, `F` включает полноэкранный режим. На слайде с регионами карточки меняют иллюстрацию; кнопка «На весь экран» открывает её целиком.
