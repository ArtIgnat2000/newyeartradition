# Волшебное путешествие

Интерактивная презентация на 13 слайдов о новогодних традициях народов России — календарном, лунном и городском Новом годе. Это единственный вариант проекта. Основа оформления — крупные иллюстрации, короткие подписи и озвучка; управляет презентацией ведущий, аудитории не нужны устройства или ответы.

## Запуск

Для корректной загрузки интерактивного глобуса как ES-модуля запустите локальный HTTP-сервер из корня проекта:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем откройте `http://localhost:8000/`. Стрелки `←` и `→` переключают слайды, `Home` и `End` ведут к началу и концу, `F` включает полноэкранный режим. На втором слайде интерактивный глобус вращается автоматически; его можно перетаскивать мышью или пальцем и приближать колёсиком/кнопками. На региональных слайдах компактная кнопка-глобус расположена рядом с озвучкой и открывает глобус с примерной отметкой; на слайде Поволжья отдельно показаны Чувашия, Марий Эл и Мордовия, а фото можно переключить на карандашную открытку. На слайде лунного Нового года представлены Калмыкия, Тыва, Алтай и Бурятия. Предпоследний слайд показывает шесть новогодних карандашных зарисовок; кнопка «Слайд-шоу» запускает просмотр зарисовок и исходных фотографий.

## Атрибуция визуальных и программных компонентов

- Текстура земного шара — **Blue Marble: Next Generation with Topography and Bathymetry (July 2004)**, NASA Earth Observatory / NASA Goddard Space Flight Center. Источник: [NASA Science](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/). Атрибуция приведена для ясности; текстура NASA получена с официальной страницы и используется как картографическая подложка.
- Рендерер глобуса — **Three.js 0.187.0**, лицензия MIT; текст лицензии находится в `vendor/THREE-LICENSE.txt`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` автоматически публикует корень репозитория при обновлении `main`. Для первичной настройки в GitHub откройте **Settings → Pages** и выберите **Build and deployment → Source: GitHub Actions**. После сохранения workflow можно запустить вручную из вкладки **Actions** или опубликовать новым коммитом в `main`.

## Фотографии городов и атрибуция

Предпоследний слайд показывает шесть явно обозначенных карандашных новогодних зарисовок по мотивам зимних городских фотографий. Каждую можно открыть отдельно; слайд-шоу включает эти рисунки и исходные фотографии с короткими подписями. Озвучка рассказывает о городах и их видах, не о лицензиях или достоверности.

- Москва, Красная площадь зимой — [Vyacheslav Argenberg, CC BY 4.0](https://commons.wikimedia.org/wiki/File:Red_Square_in_cold_winter,_Moscow,_Russia.jpg); используется сжатый веб-вариант; [лицензия CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Москва-Сити, зимний вид башен Neva Towers — Michael Manulevich, бесплатная лицензия [Pexels](https://www.pexels.com/license/); [страница фотографии](https://www.pexels.com/photo/moscow-in-winter-with-the-neva-towers-in-the-foreground-18819180/).
- Нижний Новгород, снегопад у кремля — Алексей Трефилов, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); [страница файла](https://commons.wikimedia.org/wiki/File:Snowing_in_Nzhny_Novgorod_20-02-2023_08.jpg). Фотография уменьшена и сжата для презентации; изменённый файл также распространяется по CC BY-SA 4.0.
- Санкт-Петербург, Дворцовая площадь зимой — Anna Bogatova, бесплатная лицензия [Pexels](https://www.pexels.com/license/); [страница фотографии](https://www.pexels.com/photo/stunning-winter-day-at-palace-square-st-petersburg-30697755/).
- Чебоксарский залив зимой — Алексей Белобородов, [CC BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/); [страница файла](https://commons.wikimedia.org/wiki/File:Cheboksary_Winter_Bay.jpg).

Исходные фотографии и карандашные версии хранятся локально в `images/`, чтобы презентация не зависела от внешних хостов. Новогодние зарисовки — сгенерированные художественные переосмысления по мотивам перечисленных зимних снимков; они не документируют реальное праздничное оформление. Атрибуция исходников и лицензий приведена выше, краткие подписи стоят под карточками.

На слайде о Татарстане Кар Кызы обозначена как дочь и помощница Кыш Бабая («Снежная дочь»), а не как его внучка; см. [справку официального сайта Деда Мороза](https://dedmorozonline.ru/ded_moroz/colleagues/russian_wizards/shoo_babai/).
