# Волшебное путешествие

Интерактивная презентация на 13 слайдов о новогодних традициях народов России — календарном, лунном и городском Новом годе. Это единственный вариант проекта. Основа оформления — крупные иллюстрации, короткие подписи и озвучка; управляет презентацией ведущий, аудитории не нужны устройства или ответы.

## Запуск и разработка

Для корректной загрузки интерактивного глобуса как ES-модуля запустите локальный HTTP-сервер из корня проекта:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Затем откройте `http://localhost:8000/`. Стрелки `←` и `→` переключают слайды, `Home` и `End` ведут к началу и концу, `F` включает полноэкранный режим. На втором слайде интерактивный глобус вращается автоматически; его можно перетаскивать мышью или пальцем и приближать колёсиком/кнопками. На региональных слайдах компактная кнопка-глобус расположена рядом с озвучкой и открывает глобус с примерной отметкой; на слайде Поволжья выбор Чувашии, Марий Эл или Мордовии меняет рисунок и соответствующую озвучку. На слайде лунного Нового года представлены Калмыкия, Тыва, Алтай и Бурятия. Предпоследний слайд показывает шесть карандашных рисунков городов; в слайд-шоу каждый кадр сопровождается отдельным рассказом, синхронным с изображением.

Браузерные сценарии проверяют мобильный (390×844), планшетный (768×1024) и настольный (1440×900) размеры, порядок контролов Поволжья, горизонтальное переполнение, адаптивную загрузку изображений, управление фокусом диалога и клавишу `F`.

Основные исходники разделены по назначению: разметка — `quest.html`, стили — `styles.css`, логика — `app.js`, данные карты и городской галереи — `deck-data.js`, глобус — `globe.js`. Проверки разметки и ресурсов требуют Python 3; тесты браузера — Node.js и Chromium:

```bash
python3 scripts/check_site.py
node --check app.js && node --check globe.js
npm ci
npx playwright install chromium
npm run test:e2e
python3 scripts/build_site.py
```

Для проверки собранного сайта откройте `http://localhost:8000/` после запуска сервера с каталогом `_site`:

```bash
python3 -m http.server 8000 --bind 0.0.0.0 --directory _site
```

Сборка копирует только файлы, нужные сайту; исходные альтернативные иллюстрации остаются в `images/`, но не попадают в Pages-артефакт.

## Атрибуция визуальных и программных компонентов

- Текстура земного шара — **Blue Marble: Next Generation with Topography and Bathymetry (July 2004)**, NASA Earth Observatory / NASA Goddard Space Flight Center. Источник: [NASA Science](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/). Атрибуция приведена для ясности; текстура NASA получена с официальной страницы и используется как картографическая подложка.
- Рендерер глобуса — **Three.js 0.187.0**, лицензия MIT; текст лицензии находится в `vendor/THREE-LICENSE.txt`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` проверяет HTML и локальные ресурсы в pull request, собирает компактный `_site/` и публикует его при обновлении `main`. Для первичной настройки в GitHub откройте **Settings → Pages** и выберите **Build and deployment → Source: GitHub Actions**. После сохранения workflow можно запустить вручную из вкладки **Actions** или опубликовать новым коммитом в `main`. Деплой выдерживает паузу перед публикацией из-за задержки индексации артефактов в GitHub Actions; при повторе workflow повторно использует артефакт первой попытки.

## Иллюстрации и городские зарисовки

Для слайда «Старый Новый год» создана отдельная сюжетная иллюстрация: семья встречает праздник, ребёнок переворачивает календарь с 13 на 14, на часах полночь. На слайде обычного Нового года показана та же семья в сцене подготовки и украшения ёлки. Озвучка слайда говорит «Поговорим об новогодних обычаях» — без слова «только».

На слайде 12 и в слайд-шоу используются только шесть художественных карандашных рисунков: Красная площадь, панорама Москва-Сити, башня «Меркурий», Нижегородский кремль, Дворцовая площадь и Чебоксарский залив. Все шесть файлов приведены к единому горизонтальному формату 1536 × 1024; фотографии в этой галерее не показываются. Это сгенерированные художественные изображения, а не документальные снимки.

Для рассказа о панораме Москва-Сити показана группа небоскрёбов; в отдельном кадре у башни «Меркурий» изображён праздничный мотив на верхнем медиафасаде. При запуске слайд-шоу голосовой рассказ меняется вместе с кадром. В каталоге `audio/` лежат шесть дорожек `city-*.mp3`, а также отдельные дорожки для выбранных регионов Поволжья.

Для каждого из восьми городов на интерактивном глобусе подготовлена отдельная зимняя иллюстрация в сказочном стиле; нажатие на подпись города открывает соответствующее изображение. Это художественные изображения, а не документальные фотографии.

На слайде о Татарстане Кар Кызы обозначена как дочь и помощница Кыш Бабая («Снежная дочь»), а не как его внучка; см. [справку официального сайта Деда Мороза](https://dedmorozonline.ru/ded_moroz/colleagues/russian_wizards/shoo_babai/).
